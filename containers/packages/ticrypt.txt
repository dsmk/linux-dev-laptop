# Extra packages for the 'ticrypt' flavour.
#
# This flavour is an application container, not a development one: it layers
# on distrobox.txt rather than common.txt, so it carries the distrobox host
# integration but none of the developer toolchain.
#
# tiCrypt Connect is a Wails (GTK + WebKit) desktop application. Its RPM
# declares cryptsetup-libs, gtk3 and webkit2gtk4.1; the rest is what a GUI
# application needs to look right once distrobox-export puts it on the host
# menu -- icon themes so the exported launcher resolves its icon, fonts so
# the WebKit view renders, and xdg-utils so links open on the host.

abattis-cantarell-fonts
adwaita-icon-theme
cryptsetup-libs
dbus-x11
dejavu-sans-fonts
gtk3
hicolor-icon-theme
libsecret
webkit2gtk4.1
xdg-utils
